# newappandweb

Clean-room reconstruction workspace for the authorized GameStore compatibility project.

## Project policy

This repository keeps five long-lived project state files at the repository root:

- `ROADMAP.md`
- `CHANGELOG_DEV.md`
- `HANDOFF.md`
- `PROJECT_STATE.json`
- `KNOWN_ISSUES.md`

The implementation is rebuilt from independently verified behavior and binary/interface evidence rather than recovered source code. Static evidence, automated checks, build status, runtime verification, and device verification are recorded separately.
